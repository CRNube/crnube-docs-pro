# CRNube Docs Pro — notes for Claude

Add-on of CRNube Docs (`../crnube-docs`, read its CLAUDE.md: same conventions). The user writes in Spanish; reply in Spanish. The user commits and pushes.

- Namespace `CRNube\DocsPro`, text domain `crnube-docs-pro` (`languages/crnube-docs-pro-es_CR.l10n.php`, `php bin/translations.php`). Hooks, options and tables keep the `crnd_` prefix (tables are the ones CRNube Docs ≤ 0.5 created, so data carries over).
- Boot: `crnube-docs-pro.php` runs `Pro::preload()` on plugins_loaded priority 5 (filters CRNube Docs applies while building: `crnd_access_policy`, `crnd_settings_defaults`, `crnd_settings_sanitize`), then `Pro::boot()` on `crnd_loaded`. Never reach `CRNube\Docs\Plugin::instance()` from preload filters (recursion).
- Plugs into the core only through its extension points (see core README, "Para complementos"); never edit core files to make Pro work — add an extension point there instead.
- `Access/` (groups, OTP portal, private storage, AccessSettings writes what core's DocumentAccess reads), `Analytics/` (Recorder listens to `crnd_hit`; events table, Stats, Retention), `Admin/`, `Rest/`, `License/` (client of crnube-licenses; updates verified with `CRND_PRO_RELEASE_KEY`).
- `Assistant/` (phase 7, v0.7.0): public document Q&A. `Settings` (option `crnd_ai_settings`, keys encrypted with sodium secretbox from wp_salt, or CRND_AI_API_KEY), `Providers/` (Anthropic, OpenAi, Gemini over wp_remote_post; same `Result`), `Indexer` (prepares public docs once: PDFs transcribed by the provider with [[página N]] markers, docx/xlsx locally; meta `_crnd_ai_text`; never restricted docs), `Scope` (which public docs the assistant uses: doc meta `_crnd_ai_mode` inherit/include/exclude, term meta `crnd_ai_mode` inherited down the tree, any excluded category wins; excluded docs keep their prepared text, Retriever skips them; UI: library column + category action in `assets/src/library/AssistantPicker.js`, `Admin/AssistantMetaBox`), `Retriever` (metadata + BM25 page scoring, years always covered, no match = no provider call), `Answerer` (limits, 7-day cache keyed by index version, budget pre-check, citations [n] mapped to doc/page), `Guard` (per-visitor hourly/daily limits by daily-rotating IP hash, Cloudflare Turnstile), `Usage` (table `crnd_ai_usage`, costs in micro-dollars, daily/monthly caps), `RestController` (public POST crnd/v1/assistant/ask), `Widget` ([crnube_docs_assistant], vanilla `assets/js/assistant.js`), Elementor `Integrations/AssistantWidget`, admin `Admin/AssistantPage`. Test without spending by mocking `pre_http_request`; never leave fake transcriptions in `_crnd_ai_text`.
- The license gates updates only, never features. Do not change that without the user.
- Checks: `composer check` (or `../crnube-docs/vendor/bin/phpcs|phpstan` with this folder's configs), `npm run lint:js`, `npm run build` (build/ is committed).
